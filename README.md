Personal Portfolio Website – Tanatswa
Welcome to my personal portfolio website! It is fully responsive and optimized for performance and user experience.

Home Page
Eye-catching tagline to introduce my brand
Personal avatar for identity and connection
Call-to-action buttons to guide users (View Work / Contact)

About Page
Personal background and professional summary
 Skills section with animated progress bars
 Resume section highlighting my experience and education
 
Projects Page
 A collection of projects I have successfully developed and deployed
 Interactive portfolio layout with filtering and animations
Image previews for better visual presentation

Contact Form
Contact details for easy communication
Functional contact form for sending messages directly

Technologies Used

This project was built using:
HTML5 – Structure of the website
CSS– Styling and layout
Javascript– Interactivity and functionality
Bootstrap 5– Responsive design and prebuilt UI components

Libraries and Tools
To enhance performance and user experience, I used  the following libraries 
Bootstrap Icons – For clean and modern icons
AOS (Animate On Scroll) – Smooth animations when scrolling
PureCounter.js – Animated counters for stats (projects, clients, etc.)
Waypoints – Trigger animations (e.g., skills progress bars) on scroll
GLightbox – Image lightbox for portfolio previews
ImagesLoaded – Ensures images load properly before layout rendering
Isotope – Dynamic and responsive portfolio grid layout with filtering

 Performance & Optimization
Used CDN LINKS for faster loading times,optimized for Performance and SEO (Search Engine Optimization)
Fully responsive across different devices and screen sizes made use of media queries
